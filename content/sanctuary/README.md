# Public Sanctuary manifest

manifest.json describes the public epoch shell, stable spheres and content status. Empty assets/publicEntries mean approved production assets and public catalog entries have not been added. Reference images are outside runtime resources.

This metadata is not yet a complete validated World Pack; see [World Packs](../../docs/WORLD_PACKS.md). Hidden definitions and conditions belong to a separately authorized closed package. No real recipe examples are included here. Schema/content versions, stable IDs, compatibility validation and separate backup must be defined before integrating such a package.

Localized display labels remain Russian; technical documentation and code identifiers are English.
